## DiskPulse 0.2.0 — история и графики, трей с уведомлениями, фоновая служба

Версия 0.1.0 показывала состояние дисков «сейчас»; теперь DiskPulse помнит его и предупреждает.

- **История.** Снимки раз в 30 минут (настраивается) и при запуске пишутся в файлы JSON Lines: `%APPDATA%\DiskPulse\history` или, если установлена служба, `%ProgramData%\DiskPulse\history`. SQLite не используется — это нативная C-библиотека, а данные дописываются по порядку и занимают сотни байт на снимок. Прореживание: всё за 2 суток, потом по снимку в час до 30 дней, потом по снимку в сутки до 5 лет. В файлах нет серийных номеров целиком.
- **Графики и объём записи.** Вкладка «История»: температура, Percentage Used, записано всего. «Записано за 7 / 30 дней» считается по разности счётчиков и учитывает переполнение узких счётчиков и сброс (замена диска, прошивка); показывается, за какой период реально есть данные. У SATA объём записи — оценка по атрибуту 241 (LBA по 512 Б, зависит от вендора).
- **Прогноз TBW.** Только если вы ввели заявленный производителем TBW диска и накоплено не меньше 3 дней записей; помечен «оценка» и предполагает неизменную скорость записи. Без TBW прогноза нет.
- **Трей.** `DiskPulse.exe --tray`: значок цвета худшего статуса, уведомления Windows о перегреве (порог настраивается), росте Media Errors, переназначенных и нестабильных секторов, падении Available Spare, резком скачке записи и критическом предупреждении. Одно и то же уведомление для одного диска — не чаще раза в сутки. Автозапуск и расписание — в настройках. Трей раз в сутки проверяет обновления и сообщает о новой версии.
- **Служба `DiskPulseCollector` (по желанию).** Собирает снимки без окна и без вашего входа, с правами администратора (читает и SATA). Один запрос UAC на установку и на удаление. Исполняемый файл копируется в `%ProgramFiles%\DiskPulse`, куда обычный пользователь писать не может; служба только пишет историю и читает собственный `service.json` (значения ограничены).
- `diskpulse-cli`: `collect` (снять снимок) и `history [диск] [--json] [--set-tbw ТБ]`.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `DiskPulse-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\DiskPulse`, права администратора не нужны |
| `DiskPulse.exe` | переносная версия (тот же файл), трей: `DiskPulse.exe --tray` |
| `diskpulse-cli.exe` | консольная версия: `list`, `smart`, `collect`, `history` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Права администратора нужны для SATA и USB-дисков; без них трей собирает историю только NVMe. Чтобы история SATA копилась сама, установите службу.
- Исполняемые файлы не подписаны: SmartScreen может показать «неизвестный издатель». Сверяйте `SHA256SUMS.txt`.
- Никакой телеметрии. Единственный сетевой запрос — проверка новой версии на GitHub (отключается в настройках).

**Ограничения**

- Прогноз TBW и объём записи SATA — оценки. Пока истории мало, окна «7 / 30 дней» покрывают меньше дней; это указано рядом с числом.
- Проверено в CI на реальной Windows (администратор): установка, запуск и удаление службы, запуск трея и сбор снимка. **Не проверено глазами:** внешний вид значка в трее и всплывающих уведомлений Windows; сбор SATA службой на реальном диске.
