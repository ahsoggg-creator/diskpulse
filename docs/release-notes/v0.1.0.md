## DiskPulse 0.1.0 — S.M.A.R.T. NVMe/SATA/USB, прозрачная оценка, установщик

Первый выпуск: чтение S.M.A.R.T. и оценка состояния дисков. DiskPulse только читает — на диск ничего не записывается.

- **NVMe.** Лог-страница 02h через `IOCTL_STORAGE_QUERY_PROPERTY`: температура и датчики, Percentage Used, Available Spare с порогом, записано/прочитано (128-битные счётчики не усекаются), наработка, включения, небезопасные выключения, Media Errors, критическое предупреждение. Проверено на двух реальных NVMe-дисках, причём без прав администратора.
- **SATA.** Таблица атрибутов ATA SMART с порогами (`IOCTL_ATA_PASS_THROUGH`, запасной путь `SMART_RCV_DRIVE_DATA`). Расшифрованы 5, 9, 12, 177, 187, 194, 196–198, 231, 233, 241, 242; атрибуты с вендорной трактовкой помечены, неизвестные показываются как есть. Страницы с нулями или неверной контрольной суммой отвергаются.
- **USB.** SCSI-ATA Translation (ATA PASS-THROUGH 16 → 12). Если адаптер блокирует SMART, показывается «SMART недоступен через этот USB-адаптер», а не нули. Для такого диска оценка не выставляется.
- **Оценка по прозрачным правилам.** «Хорошо / внимание / плохо» — худший уровень среди сработавших правил; правила видны в окне и в `diskpulse-cli`, у каждого указано основание (спецификация / вендор / эвристика). Процента «здоровья» нет. Порог перегрева настраивается.
- **Администратор только там, где нужно.** Основное окно без повышения; «Открыть от администратора» запускает отдельное окно (один запрос UAC).
- **Установщик.** `DiskPulse-Setup.exe` (или `--install`) ставит в `%LOCALAPPDATA%\Programs\DiskPulse` без прав администратора, добавляет ярлык «Пуск» и запись в «Приложения и возможности»; `--uninstall` удаляет; `--silent` — без окна.
- **Автообновление.** Раз в сутки запрос к `api.github.com`; кнопка «Обновление», скачивание, проверка SHA-256 по `SHA256SUMS.txt`, замена файла, перезапуск; `DiskPulse.exe --update` — без окна. Отключается в настройках.
- **Диагностика.** Журнал `%APPDATA%\DiskPulse\logs\diskpulse.log` (ротация 512 КБ), отчёты о сбое, серийные номера везде маскируются.
- Русский и английский интерфейс, `--demo` и `--screenshots` на выдуманных данных.
- `diskpulse-cli`: `list`, `smart <диск> [--json]`.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `DiskPulse-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\DiskPulse`, права администратора не нужны |
| `DiskPulse.exe` | переносная версия (тот же файл; установить можно из настроек) |
| `diskpulse-cli.exe` | консольная версия: `list`, `smart` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Для S.M.A.R.T. у SATA и USB-дисков нужны права администратора (NVMe на проверенной машине читается без них).
- Windows 11: интерфейс — обычное окно, интеграции с Проводником нет.
- Исполняемые файлы не подписаны: SmartScreen может показать предупреждение «неизвестный издатель». Сверяйте `SHA256SUMS.txt`.
- Никакой телеметрии. Единственный сетевой запрос — проверка новой версии на GitHub (отключается в настройках).

**Ограничения**

- USB-мосты часто блокируют SMART; значения атрибутов у разных вендоров трактуются по-разному; часть правил оценки — эвристики (помечены).
- NVMe-мосты JMicron/ASMedia/Realtek (вендорные команды) не реализованы.
- Проверено на реальной Windows (NVMe-диски разработчика и виртуальная машина GitHub Actions с правами администратора): перечисление дисков, чтение NVMe, статус «недоступно» для виртуального диска без нулей и без оценки, установка и удаление без окна.
- **Не проверено на реальной системе:** чтение SATA и USB (SAT) на конкретном железе (нужны права администратора и подходящий адаптер), скачивание обновления с GitHub. Эти пути покрыты тестами на байтовых образцах и чистой логике.
