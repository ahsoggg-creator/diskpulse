## DiskPulse 0.3.0 — тест чтения, файлы в медленных зонах, отчёты

DiskPulse теперь не только смотрит S.M.A.R.T., но и читает диск целиком и говорит, какие файлы лежат на медленных участках.

- **Тест чтения — только чтение.** Диск открывается с `GENERIC_READ` и `FILE_FLAG_NO_BUFFERING`, у модуля теста нет операций записи (проверяется тестом по исходнику). Блоки 1–8 МиБ подряд, время каждого блока, график скорости, гистограмма задержек, медленные зоны (порог по умолчанию 150 мс, настраивается), отмена в любой момент, диапазон «первые N ГБ». Нечитаемый блок перечитывается по 4 КиБ — так находятся точные сектора; после 2000 таких диапазонов тест останавливается.
- **Файлы в медленных зонах.** Смещение на диске переводится в кластеры тома (с учётом смещения раздела), владелец находится по `$MFT` (data runs, записи расширения, удалённые файлы игнорируются), свободное место — по `$Bitmap`. Для каждой зоны: файлы и папки с путями, служебные файлы NTFS, свободное место, «занято, владелец не найден». Для нечитаемых блоков — отдельный список. Если том не NTFS, составной или вне смонтированных томов, пишется причина.
- **Экспорт.** CSV (с защитой от формул в таблицах) и самодостаточный HTML (график, гистограмма, таблицы; всё, что пришло с диска, экранируется). В отчёте есть пути файлов — посмотрите его перед отправкой.
- `diskpulse-cli scan <диск> [--csv файл] [--html файл] [--json] [--block-mib] [--start-gb] [--len-gb] [--slow-ms]`; Ctrl+C останавливает тест и печатает то, что успело пройти.
- `docs/BENCHMARKS.md`: измеренное время запросов S.M.A.R.T. и методика. Скорости дисков не публикуются: это свойство диска.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `DiskPulse-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\DiskPulse`, права администратора не нужны |
| `DiskPulse.exe` | переносная версия (тот же файл) |
| `diskpulse-cli.exe` | консольная версия: `list`, `smart`, `collect`, `history`, `scan` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Тест чтения и определение файлов требуют прав администратора (чтение физического диска и тома): основное окно остаётся без повышения, «Открыть от администратора» запускает отдельное окно.
- Исполняемые файлы не подписаны: SmartScreen может показать «неизвестный издатель». Сверяйте `SHA256SUMS.txt`.
- Никакой телеметрии. Единственный сетевой запрос — проверка новой версии на GitHub (отключается в настройках).

**Ограничения**

- Файлы определяются только на NTFS и для томов из одного участка диска. Крошечные файлы, хранящиеся внутри записи MFT, кластеров не занимают. Жёсткие ссылки показываются под одним именем.
- Медленный участок — задержка чтения этих адресов, а не доказательство дефекта; на SSD адрес не равен физической ячейке; результат зависит от диска, кэша и нагрузки.
- Проверено в CI на реальной Windows с правами администратора: чтение первых 200 МБ тома C: (не менее 150 МБ прочитано, без нечитаемых блоков) и определение владельцев кластеров по настоящему `$MFT` — найдено 870 файлов, среди них `\$MFT` и файлы из `\Windows` и `\Program Files`. **Не проверено на реальном оборудовании:** тест чтения на физическом HDD/SSD с дефектами (нечитаемых блоков на проверенных дисках не было — этот путь покрыт тестами на имитации диска) и экспорт отчётов через диалог сохранения; скорости виртуального диска не публикуются.
