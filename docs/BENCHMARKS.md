# Измерения / Benchmarks

DiskPulse публикует только те числа, которые реально измерены; здесь описано, как. Скорость чтения самого диска зависит
от диска, а не от DiskPulse, поэтому она не публикуется как «показатель программы».

*DiskPulse publishes only numbers that were actually measured; this page says how. Disk read speed is a property of the disk,
not of DiskPulse, so it is not published as a program figure.*

## Время запросов S.M.A.R.T. / SMART query wall time

**Что мерили.** Полное время работы процесса `diskpulse-cli.exe` (запуск процесса, перечисление всех дисков, один запрос
S.M.A.R.T., печать JSON). Файл `target\release\diskpulse-cli.exe` (релизная сборка), по 20 запусков на диск, 10 для `list`;
секундомер вокруг запуска в PowerShell (`Stopwatch`).

**Машина.** AMD Ryzen 5 7500F, Windows 11 Home, 5 физических дисков (2 NVMe, 3 SATA). Запросы выполнялись без прав
администратора, поэтому читались только NVMe-диски.

| Команда | Мин. | Медиана | Макс. |
| --- | --- | --- | --- |
| `diskpulse-cli smart 3 --json` (NVMe, 512 ГБ) | 9 мс | 11 мс | 223 мс |
| `diskpulse-cli smart 4 --json` (NVMe, 256 ГБ) | 11 мс | 13 мс | 15 мс |
| `diskpulse-cli list --json` (5 дисков) | 7 мс | 8 мс | 11 мс |

Максимум 223 мс — единичный выброс, причина не выяснялась. Это время всего процесса, а не только запроса к диску; на другой
машине, с другими дисками и антивирусом числа будут другими.

## Тест чтения / Read test

Скорость и задержки блоков, которые показывает тест чтения, — это измерения вашего диска в момент теста. Никаких заранее
записанных «типичных скоростей» в программе и в README нет. Перед публикацией собственных чисел укажите: модель диска,
размер блока, диапазон, версию DiskPulse и что ещё использовало диск.

Проверка тестом на «реальной» машине (GitHub Actions, виртуальный диск Windows) выполняется в CI только как проверка
корректности: читаются первые 200 МБ тома C:, проверяется, что прочитано не меньше 150 МБ и что у зон есть файлы. Скорость
виртуального диска не публикуется.
